# Floating tools experiment

Implemented in the shared staging checkout following the Top Followers search experiment.

- Top Followers has a filter dialog in the expanded search bar, replacing voice input. The standalone capsule was removed after device review. It sorts the local archive by follower count or name and uses the widget settings segmented slider styling for minimum followers. Discrete stops include the highest loaded follower count; rounded median, 80th- and 95th-percentile presets adapt to the loaded population and remove duplicates. A live match count includes the current text query. Original ranks are retained. Filters compose with the existing text query, survive recreation, and close with Back. The dialog uses native sort radio buttons and a segmented threshold slider, OK/Cancel and a reset of the pending selections; active refinements tint both its button and the collapsed search FAB. Opening or dismissing it preserves the text query.
- Tapping a dashboard post card opens an in-place native SESL `FloatingPaneLayout` inspector. It shows cached post text and measurements, with explicit Open post and Full report actions. The pane can minimize, restore and close while the dashboard remains available. It respects window/system insets, restores the selected cached post and minimized state, and closes on account changes. No new network or AI request is made to inspect a post.
- Shared focus outlines cover focusable actions, text fields and preference rows, including separately inflated dialogs. Existing foregrounds and ripples are preserved; repeated discovery does not stack outlines. Ordinary Android focus traversal remains authoritative.
- Ctrl+F opens follower search, Ctrl+Shift+F opens the search filter dialog, Ctrl+M minimizes/restores an open inspector, and Ctrl+/ shows relevant keyboard help. Hardware-keyboard users also get a Shortcuts menu action. Native system shortcut discovery includes the same actions. Escape follows the active Back handler. AppCompat callback replacement is handled at activity start/resume.
- Search resizing use app-owned springs that retarget ongoing motion, with an immediate path when animations are disabled. Native floating-pane motion remains owned by SESL.

New labels are supplied in English, Catalan, German, Spanish and French. Tests cover threshold boundaries, retained ranks, search/filter composition and recreation, existing search Back/IME behavior, native pane lifecycle/account boundaries, settings keyboard traversal, focus composition and immediate motion. Device execution is tracked separately from compilation. The physical phone remains an install-only handoff for visual review.
