# Floating tools experiment

Implemented in the shared staging checkout following the Top Followers search experiment.

- Top Followers has a filter dialog in the expanded search bar, replacing voice input. The standalone capsule was removed after device review. It sorts the local archive by follower count or name and uses the widget settings segmented slider styling for minimum followers. The thumb moves continuously between numeric milestones (100, 1K, 10K, 100K and so on), up to the highest loaded follower count. Releasing within 6dp of a mark snaps to it; other intermediate values remain selectable. A live match count includes the current text query. Original ranks are retained. Filters compose with the existing text query, survive recreation, and close with Back. The dialog uses native sort radio buttons and a segmented threshold slider, OK/Cancel and a reset of the pending selections; active refinements tint both its button and the collapsed search FAB. Opening or dismissing it preserves the text query.
- Tapping a dashboard post card opens the tweet through the existing X launcher, using a popover when supported and normal link handling otherwise. The experimental post inspector and its minimize/restore shortcut have been removed.
- Shared focus outlines cover focusable actions, text fields and preference rows, including separately inflated dialogs. Existing foregrounds and ripples are preserved; repeated discovery does not stack outlines. Ordinary Android focus traversal remains authoritative.
- Ctrl+F opens follower search, Ctrl+Shift+F opens the search filter dialog, and Ctrl+/ shows relevant keyboard help. Hardware-keyboard users also get a Shortcuts menu action. Native system shortcut discovery includes the same actions. Escape follows the active Back handler. AppCompat callback replacement is handled at activity start/resume.
- Search resizing use app-owned springs that retarget ongoing motion, with an immediate path when animations are disabled.

New labels are supplied in English, Catalan, German, Spanish and French. Tests cover threshold boundaries, retained ranks, search/filter composition and recreation, existing search Back/IME behavior, direct tweet-card launching, settings keyboard traversal, focus composition and immediate motion. Device execution is tracked separately from compilation. The physical phone remains an install-only handoff for visual review.
